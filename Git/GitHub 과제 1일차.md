# 버전 관리(version Control)란
    - 파일이나 코드의 변경 이력을 체계적으로 기록하고 관리하며, 언제,누가 뭘 바꿨는지 알 수 있고  필요하면 과거 상태로 바꾸기 가능
    - 대표적으로 "git"에 이 기능이 있다고 함
# 바이브코딩
- 사람이 자연어로 원하는 기능을 설명하고, AI의 도움을 받아 코드를 작성하는 방식
# 운영체제(OS, Operating System)
- 컴퓨터의 하드웨어와 프로그램 실행에 필요한 자원을 관리하는 기본 소프트웨어
- 대표적인 OS: **Windows, macOS, Linux**
- Linux는 오픈소스 운영체제로, 다양한 환경에서 사용되며 특히 서버 운영에 널리 활용됨
- 리누스 토르발스(Linus Torvalds)는 Linux 커널과 Git을 만든 개발자
#  Git과 GitHub의 차이
 - Git : 버전 관리를 위한 도구 (프로그램)
          : 자신의 컴퓨터에서 동작
    - Github : Git 저장소를 올려두는 웹 서비스
             : 코드 공유 및 협업 플랫폼
=> Git 은 버전 관리 엔진 / Github 는 협업과 공유를 위한 서비스
# Git 용어
1. Repository (레포지토리)
- 프로젝트 파일과 Git 변경 이력을 관리하는 공간
2. Commit (커밋)
- 변경사항을 하나의 기록으로 저장하는 단위
3. Branch (브랜치)
-기존 개발 흐름에서 분리하여 독립적으로 작업할 수 있게 하는 기능
4. HEAD (헤드)
- 현재 체크아웃한 위치를 가리키는 포인터
